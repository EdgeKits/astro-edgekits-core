import Html from '@/components/mdx/Html.astro'

Dies ist ein ganz normaler Absatz in Markdown. Der Text, den du gerade liest, liegt im Dateisystem, direkt neben diesem Beitrag.

Der Text im Kasten unten nicht. Er ist der Newsletter-Text aus dem Namespace `newsletter`, wird für deine Sprache aus Cloudflare KV geladen und als `props.t` an diesen Beitrag übergeben:

<div class="not-prose my-6 rounded-xl border border-zinc-200 p-5">
  <p class="font-semibold">{props.t.newsletter.title}</p>
  <p class="mt-1 text-sm text-zinc-600">{props.t.newsletter.description}</p>
</div>

## Interpolation in MDX

`fmt()` füllt `{Platzhalter}` und escapt jeden eingesetzten Wert. Die Vorlage, HTML inklusive, bleibt in der JSON-Datei:

<Html html={fmt(props.t.common.ui.emphasis, { content: 'wrangler.jsonc' })} />

<Html html={fmt(props.t.common.ui.learnMore, { url: 'https://github.com/EdgeKits/astro-i18n', label: '@edgekits/astro-i18n' })} />

## Wie es funktioniert

1. Die Beitragsseite ruft `fetchTranslations(translationLocale, ['common', 'newsletter'])` auf.
2. Sie übergibt die typisierten Objekte an den Beitrag: `<Content t={{ common, newsletter }} />`.
3. Das MDX liest `props.t`, und der Server rendert reines HTML. Keine Komponente wird hydratisiert, keine Übersetzungsdatei erreicht den Browser.

Diesen Beitrag gibt es nur auf Englisch und Deutsch. Öffne ihn auf Spanisch, Japanisch oder Portugiesisch: Der Artikel fällt mit einem Hinweis und einem `noindex`-Tag auf Englisch zurück, während der Kasten oben weiterhin deine Sprache spricht, weil KV diesen Text hat.
