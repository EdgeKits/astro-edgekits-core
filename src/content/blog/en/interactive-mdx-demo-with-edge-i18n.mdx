This is a standard paragraph in Markdown. The text you are reading now lives in the filesystem, next to this post.

The text in the box below does not. It is the newsletter copy from the `newsletter` namespace, fetched from Cloudflare KV for your language and passed to this post as `props.t`:

<div class="not-prose my-6 rounded-xl border border-zinc-200 p-5">
  <p class="font-semibold">{props.t.newsletter.title}</p>
  <p class="mt-1 text-sm text-zinc-600">{props.t.newsletter.description}</p>
</div>

## Interpolation inside MDX

`fmt()` fills `{placeholders}` and escapes every value it inserts. The template, HTML included, stays in the JSON file:

<Html html={fmt(props.t.common.ui.emphasis, { content: 'wrangler.jsonc' })} />

<Html html={fmt(props.t.common.ui.learnMore, { url: 'https://github.com/EdgeKits/astro-i18n', label: '@edgekits/astro-i18n' })} />

## How it works

1. The post page calls `fetchTranslations(translationLocale, ['common', 'newsletter'])`.
2. It passes the typed objects to the post: `<Content t={{ common, newsletter }} />`.
3. The MDX reads `props.t` and the server renders plain HTML. No component hydrates and no translation file reaches the browser.

This post exists in English and German only. Open it in Spanish, Japanese or Portuguese: the article falls back to English with a notice and a canonical link to the English original, while the box above still speaks your language, because KV has that copy.
